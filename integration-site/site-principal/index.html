Qui sommes-nous

Un groupe de coachs

Nous n'étions pas satisfaits des applications disponibles sur le marché. Nous écrivions nos séances sur Excel, puis on les recopiait à la main dans une autre application pour que les athlètes puissent les voir.

Alors nous avons créé Upside Down Training, pour tout regrouper au même endroit : programmation, suivi des athlètes, cycles de force, planning hebdomadaire, scores, PR.

Développée à Besançon, testée sur notre propre box, conçue pour s'adapter à n'importe quel studio.
