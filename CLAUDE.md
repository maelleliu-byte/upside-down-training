# Upside Down Training — consignes

- **Charte visuelle obligatoire** : tout contenu créé (fiches, exports, nouveaux modules) doit suivre
  `CHARTE-VISUELLE.md`. Les fiches image passent toujours par `zones-export.js` (thème gris v2, logo,
  palette officielle). Aucun rendu maison. Les écrans des outils chargent `charte-v2.css`.
- Après une modification d'un outil chargé depuis `outils.js` (vbt.html, lv-test.html, pc.html,
  lactate.html…), incrémenter sa constante de version dans `outils.js` pour forcer le rechargement.
- Ne jamais modifier les données ou les séances d'un athlète sans l'accord explicite d'Alexis.
